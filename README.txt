DE YOUNG STARS HOME OF RESTORATION EVANGELICAL OUTREACH — website starter files

CONTENTS
- index.html: main one-page website
- styles.css: responsive design and styling
- script.js: mobile navigation and footer year
- assets/logo.png: logo supplied by the outreach

BEFORE PUBLICATION
1. Open index.html and replace the sample email and phone prompts in the Contact Us section with the official public contact details you want displayed.
2. Add verified publication download links, audio links, gallery images, and donation instructions only when ready.
3. Keep a backup of this folder before making future changes.

CLOUDFLARE
These are static website files. In Cloudflare's deployment flow, choose the option to upload static files, then upload a ZIP of these files if the dashboard accepts ZIP uploads. If the dashboard requires a folder instead, extract the ZIP first and upload the folder contents. Do not upload the ZIP as a normal public download link; deploy the contents as the site.

This starter site does not include a payment processor or collect visitor data.
